# 成员 → 开发 Agent 的「开场白」与「更新主库」模板

> 用途：每位成员第一次和"自己的开发 agent"对话时，先说这段**开场白**（让它先读文档、理解、复述，再开工）；
> 等作品完成或要更新时，再用第二段**更新指令**安全提交到主库。
> 这不是 skill，就是**第一句对话内容**。每段都有【占位符】，先照下方表格把你自己那几格填上再发给 agent。

---

## 一、先填好你自己的身份（一张表看全）

| 成员 | 数字员工 | 技能 | 你的专属文件 | 你的成员手册 |
|---|---|---|---|---|
| A | 招聘分析师 | talent.analyze | `src/main/java/com/hragent/agent/analyst/AnalystAgent.java` | `成员手册/成员A_招聘分析师.md` |
| B | 简历猎手 | resume.screen | `src/main/java/com/hragent/agent/scout/ScoutAgent.java` | `成员手册/成员B_简历猎手.md` |

| E | offer 与入职管家 | offer.onboard | `src/main/java/com/hragent/agent/concierge/ConciergeAgent.java` | `成员手册/成员E_offer管家.md` |

## 二、【第一次开发】开场白（直接复制，填【】后发给 agent）

> 我是《hr-agent-team》项目的成员**【X】**，负责数字员工**【数字员工名】**。我的专属文件是**【你的 .java 完整路径】**，技能是**【技能名】**。
>
> 请你正式开工前，先把下面这些文档**通读并理解**：
> 1. `README.md` —— 仓库结构、谁只能改哪一格；
> 2. `入门说明书.md` —— 我作为新手的开发流程；
> 3. `成员手册/成员X_数字员工名.md` —— 我的职责、技能、可验收成果、专属文件；
> 4. `SKILL-上传规则.md` —— 上传纪律（我到底能碰哪些、不能碰哪些）；
> 5. `文档库/02_契约与技能/SKILLS技能注册表.md` —— 我的技能与**输出字段/枚举**；
> 6. `文档库/02_契约与技能/工具调用规范.md` —— 我**必须在 run() 里真调用工具**把成果落成文件。
>
> 另外请打开并读完我那个 Java 骨架文件本身的现有代码。
>
> 全部读完后，**请你用自己的话向我复述一遍**：
> 「我是谁 / 我这份活做什么 / 我的 run() 输出哪些字段、枚举只能取哪些 / 我该调用哪些工具 / 我唯一能改的文件是哪个 / 哪些文件我绝对不能碰 / 上传要怎么守规矩」。
>
> 我确认你说的对之后，我们才开始开发。

---

## 三、【完成或更新时】更新主库的指令（直接复制，填【】后发给 agent）

> 我是成员**【X】**，现在要把我负责的工作更新到主仓库。
>
> 规则：
> - 本次我**只允许改动这一个文件**：【你的 .java 完整路径】；
>   - （若整合者要求我同时提交这次生成的成果文件，我会单独告诉你文件名和目录，否则成果文件先不提交）；
> - **不许改动**：`Agent.java`、`DeepSeekClient.java`、`tool/` 下任何工具类、`pom.xml`、别人的 agent、`README`/手册/文档、仓库根目录任何文件；
> - **不要提交**任何含 API key / 密钥 / 环境变量的文件；
> - 提交信息格式：`[成员X] <动词> <说明>`，例如 `[成员A] update AnalystAgent 完善ROLE与校验`；
> - 执行 `git add` 之前，**先把要 add 的路径清单逐条念给我**，我确认后才允许 add / commit / push；
> - 完成后把 `git status` 和 push 结果发给我，确认已成功同步到主库。
>
> 先告诉我：你打算 add、commit、push 哪些内容？

---

## 四、用法小结

1. **第一次开发**：先发【二】开场白 → agent 读文档并复述 → 你确认 → 开始改你的 `.java`；
2. **过程中自测**：IDEA 右键跑你的 agent `main`，能出 JSON + 生成 demo 文件即过关；
3. **完成 / 每次要更新**：发【三】更新指令 → agent 先报"要改哪些路径" → 你确认 → 它提交；
4. 全程只改你自己那一个 `.java`，成果 demo 文件默认先不提交，是否提交听整合者安排。

> 一句话：**开场先让 agent"读文档 + 复述"，动手先让它"报路径 + 确认"，更新主库就交给守规矩的 agent 去提交。**
