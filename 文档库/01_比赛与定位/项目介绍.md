# AI 招聘数字员工团队（HR Agent Team）

## 简介

本项目是一款基于大模型的多智能体招聘应用，打造一支由 5 名"数字员工"组成的 AI 招聘团队：招聘分析师、简历猎手、面试官（含命题与阅卷）、测评背调员、offer 与入职管家。

用户只需给出一句模糊的招聘诉求（如"招个会做数据的人"），整个团队即可自主接力，端到端完成**需求澄清 → 岗位描述生成 → 简历筛选 → 线上笔试 → 题库化面试 → 测评背调 → 综合评分 → offer 与入职计划**的完整招聘闭环，交付结构化岗位描述、简历初筛报告、笔试卷与笔试成绩单、面试题库与面试评分表、综合评分排名、测评背调报告、offer 草案与 30/60/90 天入职计划等 **16 类可直接验收**的工作成果——报告与网页为 HTML、汇总为 CSV，全部是真实文件，页面内可直接预览与下载。

系统后端采用 Java / Spring Boot 自研轻量多智能体框架实现：5 位数字员工实现统一的 Agent 接口、各有明确的技能与输出契约，由调度层用会话状态机串联成**可回退**的接力流程（任何一步都能退回重跑，只清该步之后的成果）。简历解析与成果落盘是**真实的工具调用**——简历猎手由模型通过 function-calling 自主决定调用简历解析工具，各环节再用 doc_writer 把结论落成真实文件；而分数、排名、权重、薪酬明细与录入门禁则**全部由确定性代码计算**，同一组输入永远得到同一个结果，可复现、可追溯；关键节点（offer 是否接受）保留人工确认。产品以网页形式交付、打开即用（前端 Vue 3 + Vite，后端 Spring Boot），并已容器化部署上线（Docker + nginx + HTTPS）。

## 面向群体

- **中小企业 HR 与招聘负责人**：缺乏专职招聘团队，招聘环节多、重复劳动重，负担不起全套专业 HR 系统；
- **业务部门负责人**：需要把模糊的用人诉求，快速变成可执行、可推进的完整招聘方案；
- **人力资源服务与就业机构**：需要批量、标准化、可追溯地处理大量招聘事务。

## 开发背景

1. **行业趋势**：AI 正从"对话式助手"迈向"自主执行"的智能体时代，业界呼唤能真正交付工作成果的"数字员工"——本项目正是对这一趋势的产品化探索。

2. **真实痛点**：一次招聘横跨需求分析、简历筛选、面试、测评、offer、入职 6 大环节，中小企业既缺人手也缺标准：需求靠口头传达、简历靠肉眼筛、面试结论留在脑子里、offer 靠拍脑袋定价，招聘质量难保证、过程难沉淀、成果难验收。

3. **技术条件**：大模型的工具调用与多智能体编排能力已趋成熟。本项目自研轻量 Agent 框架（统一 Agent 接口 + 工具注册表 + OpenAI 兼容的模型客户端），以真实可运行的 5-Agent 协同系统验证"人人可拥有的 AI 数字员工"这一命题；并用统一的技能注册表与数据契约解决多智能体之间的耦合与风格一致性问题。

## 关键能力一览（答辩速查）

| 能力 | 具体到什么程度 |
|---|---|
| 端到端闭环 | 一句诉求 → 8 个环节 → offer 与入职计划，全程可回退重跑 |
| 多智能体协同 | 5 位数字员工 + 命题/阅卷官，统一 Agent 接口与 JSON 契约 |
| 真工具调用 | 简历解析走 function-calling（模型自主决定调用）；成果由 doc_writer 落成真实文件，全项目 17 处调用点 |
| 确定性口径 | 笔试/面试加权（占比可调）、缺一轮成绩让权重、背调高风险一票否决、录用名额硬上限、同分先看风险再比初筛名次 |
| 多候选人 | 逐人并发（2 个一组）、按人切换查看、综合评分排名与 offer 汇总表横向对比 |
| 可验收成果 | 16 类 HTML/CSV 文件，页面内预览与下载（CSV 带 BOM，Excel 直接打开不乱码） |
| 人工确认 | offer 只是草案，必须人工接受/拒绝；落选通知不披露背调细节 |
| 已上线 | Docker 两容器 + nginx 反向代理 + 域名 + HTTPS |
