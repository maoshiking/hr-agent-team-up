# 成果工作台 · 规格说明（给整合者）

> 目的：把 5 个 agent 的 JSON 结果，**渲染成人可直接验收的"报告 / 表格 / 网页"**，汇成一个页面给评委看。这是比赛"结果交付与可验收性"的直接体现。
> 阶段：整合完成、后端/前端阶段做（现在先存底）。输出放 `hr-agent-team/demo/`。

---

## 1. 一句话

> **输入 = 一次招聘跑完后 5 个 agent 攒下的 JSON；输出 = 一个 `workbench.html`，里面三类齐全：报告、表格、网页。**

## 2. 数据从哪来

- 整合者在 dispatcher 里，把 A→E 每步 `run()` 返回的 JSON 累积存起来（一个候选人一个档案，见 all_skill 数据契约）；
- 一轮跑完 = 一份完整 JSON 包，就是工作台的数据源。

## 3. 每个 agent 的 JSON → 渲染成什么成果

| agent | 你的可验收成果 | 类型 | 主要用 JSON 的哪些字段 |
|---|---|---|---|
| A 招聘分析师 | 需求澄清说明 | 报告 | `demand`、追问清单 |
| A | 结构化 JD | 网页 | `jd{title,responsibilities,hard_requirements,nice_to_have}` |
| A | 候选人能力画像 | 表格 | `persona{core_competencies,...}` |
| B 简历猎手 | 简历结构化表 | 表格 | `resumes[]` 各字段 |
| B | 初筛打分表 | 表格 | `score`、`verdict`、`matched[]`、`gaps[]`、`reason` |
| C 面试官 | 面试题纲 | 网页 | `plan{questions,rubric}` |
| C | 面试纪要报告 | 报告 | `minutes{summary,qa,verdict}` |
| C | 面试评分表 | 表格 | `qa[].score`、`rubric` |
| D 测评背调员 | 技能测评报告 | 报告 | `level`、`score`、`report` |
| D | 真实性风险清单 | 表格 | `findings[]{item,risk,evidence}` |
| D | 文化匹配报告 | 报告 | `fit_score`、`fills_gap[]` |
| E offer 管家 | offer 草案 | 网页 | `offer{position,salary_range,suggested,clauses}` |
| E | 谈薪建议表 | 表格 | 薪资区间建议 |
| E | 30 天入职计划 | 网页 | `plan{week1_4,goals}`、`screening_feedback` |

> 覆盖检查：报告（A/C/D）、表格（全部）、网页（A/C/E）三类都齐。✅

## 4. 页面长什么样（板块）

`workbench.html` 自上而下：

1. **顶部**：本次招聘一句话任务 + 5 个 agent 的时间线（谁在什么阶段干了什么）—— 体现"数字员工协同、可追溯"；
2. **中部**：三类分区 —— 报告 / 表格 / 网页，每类下列出该份成果，可点击打开或下载；
3. **人工节点**：标注"offer 需人工确认"的位置；
4. **底部**：可验收性清单（每份成果按验收标准打勾）。

## 5. 三类成果的渲染规则（统一口径）

| 类型 | 形式 | 规则 |
|---|---|---|
| 报告 | 一个 HTML/MD 页 | 标题 + 分节 + 结论放前面（结论→依据→风险→下一步）|
| 表格 | CSV / HTML `<table>` | 表头固定、一行一条记录；枚举显示成中文标签（shortlist=进入下一轮 等）|
| 网页 | 独立 HTML | 结构化展示，能直接打开当"成品" |

## 6. 实现要点

- 用一个渲染脚本/页面读 JSON 包，套上面规则批量生成报告/表格/网页文件，最后汇总成 `workbench.html`；
- 表格统一为 `.csv`（Excel 能开）+ 页面里也可用 `<table>` 展示；报告/网页为 `.html`；
- 数据缺某字段时：标"N/A"，不要硬造（保住"可验收、不编造"）。

## 7. 验收清单（做完整轮必过）

- [ ] 报告、表格、网页三类**都有**，且每份能打开；
- [ ] 页面能看到 5 个 agent 谁先谁后（时间线/日志）；
- [ ] 每个枚举字段有中文可读标签；
- [ ] offer 前能看到"人工确认"节点痕迹；
- [ ] 展示用一份**真实跑通**的数据，不造假。

## 8. 提醒

这份"成果工作台"是**对外给评委的可视化门面**，也是"可验收性"的证据。整轮招聘跑通后先做出来一次，答辩演示就以它为主页 + 录屏 agent 干活过程。
