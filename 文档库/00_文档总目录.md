## 3. 使用顺序（什么阶段看什么）

1. **立项/答辩定位** → `01_比赛要点.txt` → `01_项目介绍.md`
2. **写技能前（对照字段）** → `02_SKILLS技能注册表.md` + `02_all_skill`（数据契约）
3. **开工开发（现在）** → `hr-agent-team/入门说明书.md` + 自己的 `成员手册` + `SKILL-上传规则`
4. **个人自测** → IDEA 运行自己的 agent `main`
5. **上线/答辩前** → `03_在线产品技术方案`（已是 Java/Spring 版蓝图）

> 快速版：**现在**只要 `02_SKILLS注册表` + 仓库内你的`成员手册`就够。
